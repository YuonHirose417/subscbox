利用規約

制定日・最終改定日：2026年11月10日

本アプリについて

サブスクBox（以下「本アプリ」）は、利用者が自身のサブスクリプションを手動で記録・管理するためのツールです。本アプリは各サービスの提供者とは関係がなく、各サービスと連携していません。

表示内容

本アプリに表示される金額・更新日・支払い履歴・分析結果・見直し候補は、利用者が入力した情報に基づく目安です。正確性を保証するものではありません。実際の契約内容・請求額は各サービスでご確認ください。

プレミアムプラン

プレミアムプランは買い切り（1回のみのお支払い）の商品で、自動更新や定期的な請求はありません。代金は購入の確定時に Apple ID に請求されます。購入は同じ Apple ID の端末で「購入を復元」から利用できます。返金については Apple の定める手続きに従います。

広告

無料版では広告を表示します。広告の内容は広告主の責任によるもので、開発者は広告先の商品・サービスについて責任を負いません。

データの管理

データは利用者の端末内に保存されます。端末の故障・紛失などに備え、定期的なバックアップをおすすめします。データの消失について、開発者は責任を負いかねます。

禁止事項

本アプリの改ざん・リバースエンジニアリング、その他法令に反する利用を禁止します。

変更

本規約は、本ページおよびアプリのアップデートにより変更する場合があります。
